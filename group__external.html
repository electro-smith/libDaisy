enum class daisy::Tca9534Register : uint8_t
strong

Registers for the TCA9534 8-bit I2C GPIO expander. See TI datasheet SCPS208 (TCA9534).

Note: unlike the MCP23017, the TCA9534 has no internal pull-ups. Use external resistors on input pins.
